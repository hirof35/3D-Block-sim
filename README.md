# 3D Block Breaking Game (TypeScript Edition)

HTML5 CanvasとTypeScriptで記述された、レトロな3Dワイヤーフレーム風のブロック崩しゲームです。
パドルの位置やボールの座標に応じて、カメラの角度がリアルタイムに傾くユニークな演出が特徴です。

## 🎮 ゲーム画面のイメージ

- 黒い背景に、3Dのワイヤーフレームで描かれた色鮮やかなブロック、ボール、パドルが表示されます。
- パドルを移動させると、ゲーム全体の視点（カメラ）がダイナミックに傾きます。
